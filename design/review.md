# 设计评审与验证记录

初稿日期：2026-10-23。本文记录静态页面设计验收；2026-10-24 已新增原生工程，当前实现与验证见 [implementation-status.md](../docs/implementation-status.md)。

## 交付内容

- 10 个页面/状态：四个核心页面、文件库、导入确认、编辑器、语音管理、设置和首次使用。
- 1 个深色阅读对照页，共 11 个独立 SVG；另有 3 张设计总览 SVG。
- `index.html` 是本地静态评审索引，图片可打开原始 SVG；它不执行文件管理或 TTS。
- `overview.png`、`supporting.png`、`theme-comparison.png` 提供完整画布预览。
- 产品规格、架构、分期和设计系统在项目中可追溯。

## 已完成的静态检查

- SVG XML 可解析；所有画板已通过 Chrome 渲染，人工检查核心总览、辅助总览和深色对照。
- 14 组正文/辅助文字/强调文字/主按钮前景色，在浅色与深色主题中的目标配色对比度均达到 4.5:1。具体数字见 `contrast-check.json`；这不代表所有原生系统状态已验收。
- 所有独立 SVG 的非空文字边界已核对在画板内；见 `layout-check.json`。
- 静态评审页在 375×844、844×390、768×1024、1440×1000 的容器内没有横向溢出。此结果仅适用于评审页，不是原生 App 横屏适配测试。
- 本地评审索引与 README 引用的文件已检查存在；已区分图片样例、未来播放态和无引擎状态。
- 确认第四张原参考实际为 `ui_refer/reader4.jpg`。
- Apple 官方文档的相关条目已通过公开文档数据接口核对标题与可访问性：fileImporter、安全作用域 URL、PDFDocument.string、Vision 文本识别、AVSpeechSynthesizer、AVAudioSession。

## 原生实现阶段必须验证

- Dynamic Type 最大字号、VoiceOver 遍历顺序、输入焦点、系统减少动态效果。
- 真机安全区、44pt 点击区、系统返回手势、键盘避让、横屏和 iPad 布局。
- 文件权限、导入回滚、编码、PDF 解析质量、草稿恢复和本地索引性能。
- 模型许可、资源分发、目标设备、真实离线合成、内存、耗电、延迟与音频中断。
- 原生深色控件的交互态、禁用态和非文字对比度。

以下原始记录仅针对静态稿，不能据此标记原生验收通过。静态图中展示的播放时长、字数、文件数量与容量是布局样例，不是实测或已实现功能。

## 重新生成

运行 `python3 design/render_designs.py` 重新生成 SVG 与对比度结果。PNG 由本机 Chrome 从相应 SVG 渲染。编辑或调整设计后应重新检查文字边界与预览图。
