# AI Reader 设计系统

2026-10-24 · M0 原生实现沿用的设计规则 · 依据 ui-ux-pro-max 与 `ui_refer/` 四张截图。

## 设计方向

**安静、清晰、内容优先的原生阅读工具。** 参考图里的白底、蓝紫色操作、柔和卡片与悬浮播放器保留；减少大面积阴影与无关的在线 AI 入口。页面用同一标题尺度和 4/8pt 间距节奏，正文获得最大空间。

## 检索依据与取舍

- 第一次 `reading app calm minimal --design-system` 返回 Neumorphism / 营销页结构，与原生阅读器不够匹配，未持久化该结果。
- 按规则收窄为 `ebook reader mobile library --design-system`，返回 **Minimalism & Swiss Style**。采用其功能优先、留白、高对比原则。
- 第二次结果中的 Hero/CTA 营销模板和 Google Fonts 不用于 App；其导航结构仍非原生阅读匹配。原生布局以参考图、任务流和系统惯例综合设计。
- 色彩改为参考图附近的蓝紫色；字体采用平台字体，不在离线 App 运行时加载 Google Fonts。
- 补充已核对的 UX 查询：可读正文、标签集合随字号重排、安全区、图标按钮无障碍名称。
- 用户已确认 SwiftUI；现有 `AIReader.xcodeproj` 使用 iOS 17+、SwiftUI、PDFKit，原生实现沿用本文件 token。

## 字体与排版

- 原生实现：系统 SF Pro；中文由系统中文字体回退；日语使用系统日文字体（Hiragino 系列）。设计 SVG 用同样的字体栈。
- 统一导航标题 22pt / Semibold；首页展示标题 30pt / Bold 是独立 display 角色。
- 正文阅读默认 20pt / Regular，1.75 行高；UI 正文 16–17pt。
- 卡片标题 17–18pt / Semibold；辅助信息 13–14pt。非正文微标签不小于 12pt。
- 倍速大数字 52pt / Semibold；计时使用等宽数字，避免宽度跳变。
- 优先 Dynamic Type 语义样式；字号膨胀时重排，静态图尺寸不是运行时固定高度要求。

## 间距、形状与深度

- 标准外侧间距 24pt，小屏可减至 20pt；组件内边距 16 / 20pt。
- 间距刻度：4 / 8 / 12 / 16 / 24 / 32 / 40pt。
- 卡片圆角 20pt；较小工具底 12pt；大面板顶部 32pt；按钮圆角 14pt 或胶囊。
- 卡片以浅底、边线划分；浮层与播放器使用一层轻阴影；不叠加多重拟物阴影。
- 图标统一圆角线性风格，20 / 24pt、线宽 1.8；选中底栏可改实底。原生落地建议映射到 SF Symbols。
- 不用 emoji 充当结构图标，不复制参考 App Logo 或使用未经授权的真人头像。

## 组件契约

| 组件 | 内容 | 关键状态 |
|---|---|---|
| DocumentRow | 类型、标题、语言/时间、进度、更多 | 默认、选中、解析中、失败 |
| ContinueCard | 类型、标题、位置、主入口 | 有进度、已完成、空 |
| QuickAction | 图标、标题、副说明 | 正常、按下、禁用 |
| LocalStatus | 图标、明确状态文字 | 本地优先、就绪、未接入 |
| MiniPlayer | 文档名、状态、展开/播放 | 无会话不显示；未接引擎禁用播放 |
| ReaderPlayer | 时间/进度、语音、跳句、播放、速度 | 未接入、准备、播放、暂停、失败 |
| BottomSheet | 标题、关闭、主要内容、可选 CTA | 系统下滑与明确关闭等效 |
| SearchField | 可见搜索提示、清除 | 输入、无结果、清除 |
| ImportItem | 文件信息、步骤、结果 | 等待、复制、解析、完成、失败 |
| EmptyState | 简洁线性图形、解释、下一步 | 首次使用、搜索为空、扫描 PDF |

## 交互与无障碍

- 所有操作区至少 44pt；图标本体可小于 44pt，按钮容器不能缩小。
- 滑杆有加减按钮；删除有菜单替代左滑；关键操作不依赖长按。
- 控件按下反馈约 100ms，页面约 250ms，面板约 300ms；尊重系统减少动态效果，动画均可打断。
- 装饰图形隐藏无障碍语义；图标按钮用上下文名称，如「下一句」而非「箭头」。
- 选中态同时有形状/文字；非色彩唯一表达。阅读跟随不得抢夺 VoiceOver 焦点。
- 面板打开后焦点进入标题，关闭回到触发按钮；编辑器键盘不遮挡光标、保存或错误提示。

## 页面蓝图

首页/文件库/设置：系统安全区 → 单个纵向内容容器 → 可选迷你播放器 → 三项底栏。

阅读器：系统安全区 → 紧凑页头 → 独立可滚动正文/PDF → 播放器 → 底部安全区，不出现主 Tab。

编辑器：系统安全区 → 取消/保存 → 标题/语言 → 正文编辑 → 键盘附件与保存状态。

语速/导入：保留来源页面作背景 → 遮罩 → 底部 sheet，内容过高时 sheet 内滚动。

## 适配边界

390×844pt 是设计基准；375pt 窄屏仍保持可操作；横屏播放器紧凑单行；iPad 正文限宽，文件库可发展为侧栏。真实设备安全区不可从静态图里的留白反推。

深色需独立验收；当前主要视觉稿先呈现浅色，阅读器另提供深色对照稿。本文件定义设计 token；实际模拟器截图与验证边界见 `docs/implementation-status.md`，不代表已通过全部真机/无障碍验收。
