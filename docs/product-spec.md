# AI Reader 产品与交互规格

> 此文保留 M0 规格/接口背景。2026-10-24 已接入原生日语 TTS，当前语音行为与验证以 [native-tts-integration.md](native-tts-integration.md) 为准。

初稿：2026-10-23 · 实施更新：2026-10-24 · 目标：iPhone / 日语优先 / 本地数据

本文保留目标交互规格，包含未来真实 TTS 行为；已落地功能和验证边界以 [implementation-status.md](implementation-status.md) 为准。

## 1. 产品定位与边界

把用户自己输入、粘贴或导入的日语文本，整理成可持续阅读的本地资料库；后续使用本机 TTS 朗读。核心场景是日语学习、通勤听读、长文与 PDF 阅读。

### 本轮交付

已按确认顺序创建 SwiftUI M0 工程，覆盖本地文本和文件阅读；原始静态稿用于追溯设计。**真实 TTS 尚未接入，原生页面不模拟播放。**

### 首个可运行版本（M0，当前实现）

完成本地创建、编辑、导入、解析、管理、阅读、书签和进度恢复。TTS 页面与状态预留；没有引擎时显示「语音引擎尚未接入」，播放按钮不可用。语速偏好可以保存，但不能显示虚构的播放计时或自动推进高亮。

### 日语朗读版本（M1，后续开发）

接入经过真机验证的日语端侧引擎，再开放真实播放、暂停、定位、句子跟随、后台音频和锁屏控制。音色、速度和精确时长均以引擎能力为准。

### 明确不纳入首发

账户、会员、商店、云端文件上传、云 TTS、声音克隆、AI 总结、AI 问答、AI 播客、在线网页抓取。参考图里的这些入口不直接复制，避免偏离离线阅读任务。

## 2. 信息架构

一级导航保持三项：**首页 / 文件库 / 设置**。阅读器是独立页面，打开后隐藏 Tab Bar。首页和文件库之间共享同一个阅读/播放会话。

| 层级 | 页面 / 面板 | 主要职责 | 入口 |

| 一级 | 首页 | 继续阅读、新建、导入、最近资料 | 启动默认页 |
| 一级 | 文件库 | 搜索、文件夹、筛选、排序、批量管理 | 底栏 |

| 二级 | PDF 阅读器 | 原文预览、提取文本、页码与目录 | PDF 文件 |
| 二级 | 文件夹详情 | 单一文件夹里的资料列表 | 文件库文件夹 |
| 二级 | 语音与语言 | 设备端引擎、语言包状态、兼容性说明 | 设置、播放器音色 |

## 4. 页面详细规格

### P01 首页

- 系统状态栏：遵守原生安全区，不自绘系统状态图标。
- 页头：品牌图形、AI Reader、状态标签「本地优先」。无登录头像。
- 主内容：标题「让文字，慢慢说。」；一张继续阅读卡（标题、类型、语言、文本进度、继续阅读）；无记录时换成首次导入引导。
- 快捷操作：新建文本、粘贴文本、导入文件。都带图标与文字，触摸区域不小于 44pt。
- 次内容：最近添加最多三项、查看全部；状态提示说明内容保存在本机。
- 底栏：首页 / 文件库 / 设置。存在会话时迷你播放器位于底栏上方，内容留出对应底部空间。
- 排序：继续阅读取最近打开且未完成的项目；已读完的项目不抢占「继续」。

### P02 文本阅读器

- 系统安全区 + 页头：返回、标题、编辑、更多。标题可截断；更多中能查看完整名称。
- 阅读正文：日语默认 20pt、行高约 1.75，可调 17–30pt；清晰段落。书签、查找、Aa 为辅助工具。
- 真正接入语音后：当前句浅紫底，当前词若引擎提供精确边界才用较深高亮。不能靠分词猜测伪造词级同步。
- 用户手动滚动后暂停自动跟随，显示「回到朗读位置」；跳转至所选句需明确操作，不能与文本选择冲突。
- 底部：语音、上一句、播放/暂停、下一句、语速；上方显示进度和真实/预计时长标识。上一/下一句优先于 ±10 秒，后者仅在引擎提供音频时间轴时开放。
- M0：正常看文、查找、加书签；播放器显示「语音引擎尚未接入」，播放禁用，无走动时间。
- 返回保留位置与会话；关闭播放器表示结束会话，与导航返回不同。

### P03 文本编辑器

- 新建时标题可空，保存使用首行摘要生成标题；正文空白时保存按钮禁用并显示原因。
- 表单有可见标签：标题、正文、朗读语言。日语为默认值，不靠自动识别覆盖用户选择。
- 提供清空正文、手动粘贴、撤销/重做。访问剪贴板只由用户点击触发。
- 500ms 防抖保存草稿，离开前完成落盘；显示「保存中 / 已保存到本机 / 保存失败，重试」。失败时仍保留编辑内容。
- 编辑已有资料生成新 contentRevision；保存后使旧分句、进度映射、音频缓存失效。优先保留段落锚点，无法映射就明确提示重新定位。
- PDF 原文件不可编辑；提取文字可「保存副本并编辑」，不能悄悄改写 PDF。
- 键盘显示时隐藏播放器与主 Tab，操作条贴键盘上方；正文自动滚动至光标。

### P04 语速调整面板

- 从播放器倍速按钮弹出，背景加遮罩，提供关闭按钮和系统下滑关闭。
- 主区：当前倍速、减/加、水平滑杆；步长建议 0.05×。预设：0.75 / 1.0 / 1.25 / 1.5 / 1.75 / 2.0。
- 数值范围是设计目标（0.5–2.0×），实际上下限由引擎 capabilities 决定。能力不满足时限制范围并解释，不将系统 rate 直接等同于精确倍速。
- 修改立即更新会话偏好；面板有「设为默认」独立开关，不自动改其他文档的设置。
- 有可靠时间轴时才显示预计剩余时长；否则显示「合成后显示时长」。不能直接用字数生成貌似精确的分钟秒数。
- 未来引擎不支持实时变速时：显示「下一句生效」，拖动结束时提交，防止反复合成。
- M0：允许调整并保存偏好，显示「接入语音后生效」；无试听按钮。

### P05 PDF / TXT 文件阅读

- PDF 页头显示文档名；「原文 / 文本」分段切换。原文双指缩放与纵向翻页；文本模式适合大字号阅读。
- 页码「2 / 24」与目录/缩略图入口；跳页输入范围校验。存在 PDF 大纲则显示，否则仅提供页面缩略图。
- PDF 文本解析建立 pageIndex + 归一化 range + 原页区域映射；只在可靠映射下同步页内高亮。
- 多栏、竖排、扫描页、缺字时给出「阅读顺序可能不准确」，允许预览提取文本后保存校正版。
- 无可提取文本：显示「这是扫描版 PDF」，提供以后加入的本地 OCR 说明；M0 不出现无法工作的 OCR 按钮。
- 加密 PDF：要求本次解锁，不持久化明文密码。损坏、无权限、复制限制时停止解析并给出原因。
- TXT 进入文本阅读器，保留源文件信息。编码依次识别 BOM / UTF-8；失败后由用户选择 Shift-JIS、UTF-16、GB18030 并预览，不静默产生乱码。
- 底部与文本阅读器共用播放器。读到下一页不改变用户主动查看的页面，除非开启跟随。

### P06 文件库与文件夹

- 页头：文件库、添加、更多。搜索标题与本地纯文本索引；筛选全部 / 文本 / PDF / 收藏。
- 排序：最近打开、添加时间、标题；默认最近打开。空结果明确区分「没有文件」与「没有搜索结果」。
- 文件夹支持新建、重命名、移动；首发仅一层文件夹，降低递归与移动复杂度。
- 资料行：类型图标、完整可访问名称、语言、修改日期、文本进度；长按与更多菜单提供同一组操作。
- 批量模式：移动、收藏、删除；选中数明确；删除弹确认并进入最近删除。
- 最近删除默认保留 30 天（产品设定）；启动或前台维护时清理到期记录，不承诺系统后台精确定时执行。永久删除需二次确认。
- 导出原文件和 TXT 文本副本走系统分享；删除资料时同时清理专属文件、解析缓存与音频缓存。

### P07 添加与导入

- 这里的「上传」指用户选择后复制进 App 本地目录；界面统一叫「导入文件」。系统文件 App 里的 iCloud 文件可能由系统先下载，本 App 不会将文件上传到服务器。
- 首发支持 PDF / TXT / MD（MD 先纯文本显示）；拒绝其他后缀并解释。首发建议上限：单文件 50MB、PDF 300 页、文本 20 万字符，均属待真机验证的保护阈值。
- 选择后显示名称、类型、大小、默认日语、目标文件夹和重复文件提示；确认才导入。
- 状态：等待 → 复制本地 → 解析 → 完成 / 失败 / 取消。未知总工作量显示步骤，不伪造百分比。
- 重复以文件内容摘要识别；提供「打开已有 / 仍导入副本 / 取消」。重名文件使用可追溯后缀，不覆盖原文件。
- 批量导入逐项展示结果；失败可单项重试，取消只取消未完成项目，完成项保留。
- 导入失败不留下列表里的空文档；原始文件保持可访问的本地副本时允许重试解析。
- 外部分享至 App 作为第二阶段扩展；M0 使用系统文件选择器，不默认已有 Share Extension。

### P08 语音与语言

- 首发语言：日本語 / ja-JP。其他语言不展示成可下载的可用选项，扩展时按语言能力注册。
- 无引擎时显示「尚未接入」，说明文本阅读和管理仍可用。设计图的音色卡只是未来状态示意。
- 后续区分「系统设备语音」与「随 App 提供的模型」；两者都本机合成。系统语音依赖设备安装状态，自带模型要管理存储、许可与校验。
- 建议日语基础模型随 App 提供，以支持安装后无需再联网准备；模型体积与包体策略由后续选型实测决定。
- 若后续采用可选下载，只下载模型文件，不上传文本；明确区分「推理离线」和「准备阶段需要网络」，不能都宣传成首次启动完全离线。
- 能力卡包含语言、可用状态、提供方、许可、版本、实际大小；不承诺未验证的音色数量、自然度或设备兼容性。
- 真正可用时才开放试听和选择；资源缺失、损坏、不兼容和空间不足均有恢复路径。

### P09 设置与存储

- 阅读：字号、行距、跟随、浅色/深色/跟随系统。
- 播放偏好：默认语言、默认语速、定时停止（M1）；保留文档覆盖值。
- 本地存储：原文件、解析缓存、音频缓存分别列出实际容量。清理缓存不删除原文件和书签。
- 隐私说明：无账户、文本不发往 TTS 服务；实际权限和网络行为必须和实现一致。
- 危险区：清空资料要独立确认，准确列出受影响内容。导出资料后再重置作为建议，不强制上传备份。
- 关于：版本、开源许可、反馈说明。无客服聊天、无远程 AI 入口。

## 5. 核心流程

### F01 手动文本

首页 → 新建 / 用户点击粘贴 → 编辑标题和正文 → 保存到本地 → 文本阅读器 → 书签/显示偏好 → 返回 → 首页继续阅读恢复位置。

### F02 文件导入

首页 / 文件库 → 添加 → 系统文件选择 → 导入确认 → 本地复制与解析 → PDF 原文 / TXT 阅读 → 文件库记录。异常返回导入任务，不丢失其他已完成项目。

### F03 未来语音

阅读器 → 检查本地引擎与语言能力 → 句子切分 → 本机合成 → 缓冲 → 播放 → 句级进度/高亮 → 暂停/恢复 → 自动保存会话位置。

### F04 修改正文

阅读器 → 编辑 → 暂停会话 → 保存新版本 → 废弃旧文本的合成任务和音频 → 重建分句 → 还原可映射的位置 / 提示重新定位。不得播放旧文本却高亮新文本。

## 6. 状态与反馈矩阵

| 对象 | 状态 | 文案与恢复 |
|---|---|---|
| 首页 | 无资料 | 「从第一段日语开始」+ 新建 / 导入 |
| 文件库 | 无搜索结果 | 保留关键词、清除筛选 |
| 编辑器 | 保存失败 | 保留内存草稿，重试；离开前提示 |
| 导入 | 文件不可访问 | 重新选择，解释权限已失效 |
| 导入 | 空间不足 | 取消复制，前往存储管理 |
| TXT | 编码不明 | 编码选择与预览，不直接确认 |
| PDF | 无文本层 | 原文仍可看，提示本地 OCR 后续提供 |
| PDF | 部分页无文字 | 列出页码，不默默跳过后标为完整解析 |
| TTS | 未接入 / 语言不可用 | 禁用播放并解释；允许继续阅读 |
| TTS | 资源缺失 / 校验失败 | 提供恢复步骤，不自动切远程服务 |
| TTS | 合成慢 / 设备过热 | 显示准备状态，取消与降负载；不持续占满内存 |
| 音频 | 电话 / 耳机断开 | 暂停；遵循系统音频会话策略恢复 |
| 后台 | 系统终止 | 下次启动恢复到最近确认的句子位置 |
| 删除 | 可恢复 / 永久删除 | 明确保留天数；最终删除需确认 |

## 7. 离线、无障碍与适配要求

- 飞行模式下可创建、编辑、导入设备已有文件、查看、搜索、书签和恢复进度。未来语音验收还必须验证已具备资源时的离线合成。
- 远程文件提供器的下载能力不等于本地导入能力；UI 要提示文件尚未下载。
- 所有主要点击区 ≥44×44pt；滑杆配加减；所有图标按钮有 VoiceOver 名称与状态。
- 正文/辅助文本对比度目标 ≥4.5:1，重要非文字图标 ≥3:1。选中和错误都有文字/图形线索。
- Dynamic Type 最大字号时卡片纵向展开、工具栏可收纳为「更多」；不强制缩字到不可读。
- 375pt 小屏、横屏、iPad 单列宽度约 680pt 内阅读。安全区使用系统值而非固定假状态栏高度。
- 减少动态效果时取消非必要位移、波形和自动滚动动画；用户滚动优先。
- VoiceOver 不逐词播报 TTS 高亮，避免与主语音重叠；状态播报低频且可关闭。
